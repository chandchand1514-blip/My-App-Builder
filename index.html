Apps load ho rahe hain…

1. App ki pehchan aur website

Yahan app ka naam, Android package aur woh website bharein jise APK mein chalana hai.

Lowercase letters, numbers aur dots. Example: com.company.shop

2. App icon, splash screen aur rang

App install hone par icon aur app khulte waqt splash screen dikhegi.

Square PNG recommended, 512×512. Image public URL se accessible honi chahiye.

3. Login Callback / Deep Link Settings

Google login ya website login ke baad app mein wapas aane ke liye callback URL yahan bharein. Example: staffpro://auth/callback

Is URL ko Supabase Authentication → URL Configuration → Redirect URLs mein allow karein. Website ke OAuth redirectTo mein bhi isi URL ka use karein. Website ko callback event handle karna hoga.
Iske liye website domain par /.well-known/assetlinks.json mein app package aur signing certificate SHA-256 set karna zaroori hai.
\n

4. Android permissions

Sirf wahi permissions ON karein jo aapki app ko waqai chahiye.

5. Android plugins

Selected plugins Android build mein install honge; kuch features ko app website mein integration bhi chahiye.

6. App chalne ka behaviour

Supabase + Google login: Supabase Redirect URLs mein app callback add karein. Google Cloud Console mein Supabase ka Auth callback URL (https://PROJECT.supabase.co/auth/v1/callback) hi Authorized redirect URI rahega. Website ko app callback event bhi handle karna hoga.
Build status yahan dikhega. APK build hone ke baad neeche download link aayega.
My App Builder · Build cloud par GitHub Actions se hota hai. APK ko phone par install karne se pehle permissions check karein.
